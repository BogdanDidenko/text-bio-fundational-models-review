# Data transformation library

The page catalogs reusable operations and shows their actual data-to-model chains.
Each operation has named ports, instance parameters, source-backed applications
and distinct-paper reuse counts. Data/resource nodes keep biological content and
symbolic shapes. Whole modules with unresolved internals remain visible in the
Unexpanded Steps view.

The canonical source is `analysis/representation_block_library_2026-10-04/operation_catalog.json`.
Use `scripts/build_representation_library.py` to rebuild/check the downloadable
JSON and schemas. The shared agent protocol is `protocol/REPRESENTATION_LIBRARY_GUIDE.md`.

The same existing Pages workflow publishes `/component-library/`. Current atlas
data remain unchanged. The previous 91-entry catalog has been removed from the
active tree and is recoverable in Git history.
