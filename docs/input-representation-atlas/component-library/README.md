# Representation Component Library

Static catalog deployed beside the existing evidence atlas at:
https://bogdandidenko.github.io/text-bio-fundational-models-review/component-library/

The four views are reusable building blocks, source assemblies, extension proposals
and the steward's scientific decision ledger. Examples include complete quoted
evidence, recovered-Markdown headings, section hashes, explicit operands, symbolic
shapes and links to original-paper figures already preserved in the atlas.

This is a supervised development candidate derived from four difficult papers.
The canonical taxonomy and its corpus denominators are unchanged. Mechanical
source matching and graph validation are reported separately from scientific
entailment. Missing PDF item coordinates and unresolved transformations remain
visible in the data.

Build/check instructions and the agent procedures are in
`protocol/REPRESENTATION_LIBRARY_GUIDE.md`. Data are generated by
`scripts/build_representation_library.py`; change only source definitions and
reviewed input artifacts, then rebuild. The published release is hash-pinned.

The page has no write backend. Catalog changes pass through the repository's
steward review and versioned release procedure. Downloadable JSON and JSON Schema
are included in `data/`.

For local inspection serve the existing atlas root:

```bash
python -m http.server 8766 --bind 127.0.0.1 --directory docs/input-representation-atlas
```

Open `http://127.0.0.1:8766/component-library/`. Browser QA uses
`scripts/qa_representation_library.mjs` with the project's existing Playwright
setup and checks desktop/mobile filters, evidence, source assets and assemblies.
