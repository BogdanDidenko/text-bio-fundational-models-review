# Paper 1 in the OUP authoring template

`main.pdf` is the manuscript "Translate or encode? Two design cultures for coupling language and omics
data in generative foundation models: a scoping review" (draft v0.5.1). It is typeset with the OUP
authoring template (`oup-authoring-template.cls`, TeX Live 2026; layout `contemporary`, `large`).
The front matter follows common OUP requirements for methodology reviews (title page, short abstract,
keywords, Key Points, statements, author biographies). The files do not name a target journal.

## Files

| File | Role | Edited by |
|---|---|---|
| `main.tex` | title page, short abstract, keywords, Key Points, statements, biographies | hand |
| `body.tex` | sections 1-5, tables, Box 1, figure floats | generated by `scripts/build_manuscript_latex.py` from `../review_manuscript_draft.md` |
| `supplementary.tex` | list of supplementary items with repository paths | generated (same script) |
| `references.bib` | 80 entries: the 55 included records and 25 works named in the text | generated by `scripts/build_manuscript_references.py` |
| `references_audit.csv` | identifier, source and title check of every entry | generated (same script) |
| `references_cache/` | raw Crossref, arXiv and Europe PMC responses, so the bibliography builds offline | generated |
| `figures/` | copies of the paper figures (Figures 1, 3-5 from `analysis/design_culture_charting_2026-10-14/v11/figures/`, Figure 2 panels from `analysis/prisma_flow_2026-10-07/` and `analysis/review_synthesis_2026-10-07/`) | generated |
| `vancouver-draft.bst` | modified copy of `vancouver.bst` (LPPL): prints "et al." once and DOIs as `doi:` | hand |

The Markdown file remains the master text. Change it, then rebuild:

```bash
python3 scripts/build_manuscript_references.py --offline   # only if references changed; drop --offline to fetch new ones
python3 scripts/build_manuscript_latex.py
cd manuscript/latex && latexmk -pdf main.tex                # or pdflatex, bibtex, pdflatex, pdflatex
```

## How the conversion treats the text

- Each included work, guideline, tool or comparator named in the text is cited at its first mention.
  All 55 included records are cited together where the inclusion count is reported (section 3.1).
- Bibliographic data come from Crossref (DOIs), the arXiv API and Europe PMC; every included-record title
  was compared with the corpus title (`references_audit.csv`; all at least 0.89 similar, RVQ-Alpha's
  title changed between versions).
- The `[CITE ...]` placeholders of the draft are printed in red. They are left for the authors.
- Sections 4.3 and 4.4 point to Box 1, which holds the comparison protocol and the reporting card.
- The long Markdown abstract (640 words) is replaced by a short abstract of 243 words in `main.tex`.
- Figure legends come from the "Figures and tables" list of the Markdown file, without file paths.
