# Paper 1 in the OUP authoring template

`main.pdf` is the manuscript "Translate or encode? Two design cultures for coupling language and omics
data in generative foundation models: a scoping review" (draft v0.6, journal version). It is typeset
with the OUP authoring template (`oup-authoring-template.cls`, TeX Live 2026; layout `contemporary`,
`large`). The files do not name a target journal.

## Files

| File | Role | Edited by |
|---|---|---|
| `main.tex` | title page (authors, affiliations, correspondence) and the order of the parts | hand |
| `frontmatter.tex`, `keypoints.tex` | abstract, keywords and Key Points | generated from `../review_manuscript_draft.md` |
| `body.tex` | Introduction to Conclusions, tables, Box 1, figure floats | generated (same source) |
| `backmatter.tex`, `biographies.tex` | statements and biographical notes | generated (same source) |
| `references.bib` | the 55 included records and the works named in the text | generated by `scripts/build_manuscript_references.py` |
| `references_audit.csv` | identifier, source and title check of every entry | generated (same script) |
| `references_cache/` | raw Crossref, arXiv and Europe PMC responses, so the bibliography builds offline | generated |
| `figures/` | copies of the paper figures | generated |
| `vancouver-draft.bst` | modified copy of `vancouver.bst` (LPPL): prints "et al." once and DOIs as `doi:` | hand |

The Markdown file is the master text; the Supplementary Information has its own source
(`../supplementary_information.md`). Change the sources, then rebuild both documents:

```bash
python3 scripts/build_manuscript_references.py --offline   # only if references changed; drop --offline to fetch new ones
python3 scripts/build_manuscript.py                        # article (this folder) and supplement (../build/)
python3 scripts/manuscript_rewrite_audit.py                # label census, number check, move list, lengths
```

`scripts/build_manuscript.py` first resolves the Markdown master into `../build/manuscript.md`
(supplementary numbers, generated counts, build commit), converts it with
`scripts/build_manuscript_latex.py` and runs pdfLaTeX and BibTeX here; it then builds the supplement
with study labels and reference numbers read from this folder's bibliography.

## How the conversion treats the text

- Each included work, guideline, tool or comparator named in the text is cited at its first mention.
  All 55 included records are cited together where the inclusion is reported (Results, selection of
  sources of evidence); the build fails if that sentence is not found.
- Bibliographic data come from Crossref (DOIs), the arXiv API and Europe PMC; every included-record title
  was compared with the corpus title (`references_audit.csv`).
- `[CITE ...]` and `[TODO ...]` placeholders are printed in red. They are left for the authors.
- The subsections "A neutral comparison protocol" and "A reporting card for input representations"
  point to Box 1, which holds the protocol and the card.
- Figure legends come from the "Figure legends" list of the Markdown file.

Lengths and counts against the target conventions are in `../journal_rewrite/COMPLIANCE.md`; the open
items are listed in `../journal_rewrite/CHANGE_LOG.md`.
