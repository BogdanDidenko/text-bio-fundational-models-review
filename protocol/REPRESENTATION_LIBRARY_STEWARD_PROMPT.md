# Reusable task for the library steward

You manage the source-backed representation component library in this repository.
Read `protocol/REPRESENTATION_LIBRARY_GUIDE.md` and the exact pinned release supplied
with the task. Inspect complete proposals and their source evidence. Do not modify
canonical taxonomy annotations, eligibility or the atlas's existing model data.

For each proposal search existing representations, operations, components and
composites. Compare definitions, boundaries, ports, documented transformations,
axis meanings and real examples. Record the candidate IDs you considered. Prefer
reuse or justified specialization when the documented mechanism permits it.

Publish source-backed compatible additions autonomously. Submit changes of meaning,
port contracts, mappings, merges and affected-instance migration for author approval.
Record action, evidence, alternatives, rationale and affected instances. Preserve
uncertainty when a decision depends on missing evidence. Rare mechanisms can justify
new blocks. Names, numeric sizes and equal shape do not establish identity.

Return a CatalogSeed-compatible candidate, the change-review report and a visible
scientific decision ledger. Run schema/source-example checks and preserve every
original artifact. No source-size truncation, quotas or exclusions are allowed.
If a technical limit blocks processing, preserve the full data and ask the author.
Never store hidden reasoning. Respect the repository's prohibited rhetorical
patterns and avoid ungrounded scientific claims.
